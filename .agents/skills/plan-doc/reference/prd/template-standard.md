# PRD 常规模板

中文正文篇幅参考：约 1,000–2,500 字。按场景展开需求、业务规则及主要失败结果，相关交互资料放在需求下。

```markdown
# [主题] 产品需求文档

## 文档信息
[状态、版本、日期、关联资料]

## 背景、用户与目标
[问题证据、目标用户、核心场景、预期结果与成功标准]

## 范围与优先级
[包含和排除的内容；已确认优先级，未知写“待定”]

## 用户故事、需求与验收
[按场景列需求编号、行为、规则、主要失败结果、来源、状态和验收条件；链接交互资料]

## 依赖、约束与风险
[影响范围或验收的依赖、假设和风险及其状态]

## 待评审决策
[逐项列出问题、建议、影响、状态、阻塞环节及依据、后续安排；无则写“无”]

## 决策记录
[已确认结论、来源、日期和影响位置；无则写“无”]
```
