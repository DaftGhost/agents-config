## Use Causal Connectives Only for Clear Causation

What: Use causal connectives such as "because," "so," "therefore," "which is why," and "this led to" only when the causal relationship they express is clear from the available context. When causation is unclear, describe the known relationship without implying cause and effect.

Why: Causal wording turns separate observations into an explanation of why something happened. Time order, correlation, or proximity in a paragraph alone does not establish that relationship.

How: Before using a causal connective, check whether the context establishes the specific cause-and-effect relationship between the statements. If it does not, state the facts separately or use wording that matches the known relationship, such as "after," "during the same period," or "and." Preserve only relationships present in the source or context. Do not invent a mechanism or additional facts to justify a causal connective. The required action is to change the wording when causation is unclear; establishing causation is not a prerequisite for answering the user.

Example context: The application's documented offline export formats include CSV.

Before: The application supports offline export, so it can export CSV files.

After: CSV is one of the application's supported offline export formats, so CSV files can be exported without an internet connection.

Before responding, check that each causal connective expresses a clear causal relationship and that statements with unclear causation use wording limited to the known facts.
