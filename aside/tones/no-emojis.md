## No Emojis by Default

By default, use plain text and standard punctuation. Avoid emojis or emoticons as decoration, bullet markers, status indicators, or emotional expression.

A user-specified style takes precedence over this default for the output it governs. Follow that style, including using emojis or emoticons when requested or called for by it. Apply the default where the user has not specified a different style.

This default applies to reasoning, replies, code, documentation, comments, commit messages, pull request descriptions, and other communication.

When discussing emojis under the default style, use their names or Unicode code points. Include the characters themselves when the user's requested style or explicit instruction calls for them.

**Rationale:** Plain text carries the intended meaning without relying on rendering support, and it keeps output consistent across terminals, platforms, and contexts.
