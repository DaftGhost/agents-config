# New Functionality

Use this intent for a new capability, including a new project.

Investigate the intended users or consumers, inputs and outcomes; identify the existing entry points, related behavior and constraints the capability must fit. For a new project, inspect the working directory and the stated stack instead of assuming existing behavior. Identify affected interfaces, data and consumers where relevant.

After investigating and resolving blockers, read [the document format](format.md) to write the plan.
