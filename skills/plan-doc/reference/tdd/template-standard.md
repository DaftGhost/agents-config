# TDD 常规模板

中文正文篇幅参考：约 1,500–3,000 字。将相关数据与接口、异常与权限分别集中描述，验证按需求追踪。

```markdown
# [主题] 技术设计文档

## 文档信息与需求基线
[状态、版本、日期、需求来源、版本和确认状态]

## 现状、范围与依赖
[代码证据、受影响与排除的范围、外部依赖和约束]

## 方案与变更边界
[组件职责、依赖方向、数据流、新增与修改对象及位置；关联需求]

## 数据、接口与关键流程
[受影响的数据和接口契约、状态与关键分支；按需配图]

## 异常、权限与可观测性
[主要失败结果、权限校验、排查和观测方式]

## 验证与发布
[需求到设计及验证的追踪、通过标准、适用的发布、兼容和回滚安排]

## 风险与开放问题
[影响、选项、建议、状态、阻塞环节及依据、后续安排；无则写“无”]

## 决策记录
[已确认结论、来源、日期和回填位置；无则写“无”]
```
