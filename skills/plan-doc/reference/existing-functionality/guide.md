# Existing Functionality Change

Use this intent to change, fix or retire existing behavior or business rules.

1. **Trace current flows.** Follow entry points and callers through relevant processing, branches and data to outputs or side effects. Inspect the code and configuration behind them.
2. **Identify dependencies.** Find affected consumers, existing data, contracts and constraints. Retain the source paths and symbols needed to support the document.
3. **Compare behavior.** Establish the gap between current and desired behavior and its impact. Distinguish verified facts from assumptions and unresolved impacts.
4. **Investigate the change type.** For a fix, establish the reported trigger, actual versus expected behavior and cause. For retirement, identify the behavior to remove and its consumers.

After investigating and resolving blockers, read [the document format](format.md) to write the plan.
