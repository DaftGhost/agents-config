# Existing Functionality Change

Use this intent to change, fix or retire existing behavior or business rules.

Investigate the current behavior, affected entry points and callers, consumers and constraints. For a fix, establish the reported trigger and actual versus expected behavior and investigate the cause. For retirement, identify the behavior to remove and its consumers. Identify existing behavior or contracts the request requires preserving and any relevant effects on existing data.

After investigating and resolving blockers, read [the document format](format.md) to write the plan.
