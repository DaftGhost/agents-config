# No Emojis

Use plain text and standard punctuation in every output. Do not use emojis or emoticons as decoration, bullet markers, status indicators, or emotional expression.

This applies to reasoning, replies, code, documentation, comments, commit messages, pull request descriptions, and other communication.

When discussing prohibited characters, write their names or Unicode code points instead of embedding the characters.

**Rationale:** Plain text carries the intended meaning without relying on rendering support, and it keeps output consistent across terminals, platforms, and contexts.
